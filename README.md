# Deep Learning from Scratch

A hands-on deep learning repository focused on understanding neural networks and computer vision by implementing core concepts with **Python and NumPy**.

The goal is to move beyond using high-level frameworks and understand the mathematics, tensor operations, and algorithms that make deep learning systems work.

## 📚 Repository Structure

The work is organized into modules so that concepts, implementations, experiments, and notes can be developed incrementally.

### Current focus

- Convolutional Neural Networks
- Convolution and padding
- Stride and output-shape calculations
- Multi-channel convolution
- Multi-filter convolution
- CNN building blocks and experiments
- Implementations following the notation and concepts used in the **Deep Learning Specialization by Andrew Ng**

### Planned / expanding topics

- Deeper CNN architectures
- Object detection
- Face recognition
- Neural style transfer
- Additional deep learning experiments and implementations

## 🛠️ Technologies

- Python
- NumPy
- Jupyter Notebook
- Git & GitHub

## 🎯 Learning Approach

Each module is built around the same workflow:

1. Understand the mathematical concept
2. Derive the required operations
3. Implement the concept from scratch
4. Write tests for important edge cases
5. Run experiments and visualizations
6. Document the implementation and observations

This repository is a learning project focused on understanding **how deep learning works under the hood**.
